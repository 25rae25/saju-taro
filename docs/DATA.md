# 데이터 출처·규칙·검증

이 앱은 계산이 정확해야 결과를 믿을 수 있으므로, 모든 데이터는 **출처가 분명하고 다시 만들어 낼 수 있게** 두었다.
런타임은 `src/data/`의 고정 파일만 읽는다. 생성 스크립트는 `scripts/`, 검증은 `tests/`에 있다.

## 1. 만세력·절기

| 데이터 | 파일 | 출처 | 라이선스 |
|---|---|---|---|
| 24절기 진입 시각 1899–2101 (UTC, 초) | `src/data/solar-terms.json` | lunar-javascript 1.7.7 (寿星天文历 알고리즘)로 생성, astronomy-engine 2.1.19로 교차 검증 | 둘 다 MIT |
| 한국 표준시 변천 | `src/data/seoul-tz.json` | IANA tz database 2026a (Node ICU) | 퍼블릭 도메인 |
| 음력 ↔ 양력 | `korean-lunar-calendar` 0.4.0 (버전 고정) | 한국천문연구원 기준 데이터 (음력 1000-01-01 ~ 2050-11-18) | MIT |
| 출생지 경도 | `src/lib/saju/places.ts` | 시청 소재지 경도 (사실 정보) | – |

### 절기 정확도
- 한국천문연구원 달력자료 2021–2028의 24절기 192개(분 단위, 반올림)와 비교했다. 저장값을 분 단위로 반올림하면 **187개가 KASI와 같고**, 나머지 5개도 ±31초 이내다. 반올림 경계(×× 분 30초 부근)에 걸린 값들이다.
- astronomy-engine은 같은 비교에서 최대 59초까지 어긋났다. 그래서 1차 값이 아니라 독립 교차 검증(±90초)에만 쓴다.
- 1899–2101 전체에서 두 계산의 차이는 최대 62초다(2098년 입춘).
- 다시 생성하려면 `npm run gen:terms`를 실행한다. 교차 검증 범위를 넘으면 생성이 중단된다.

### 표준시 변천 (Asia/Seoul)
| 기간 | UTC 오프셋 |
|---|---|
| ~1908-04-01 | +8:27:52 (지방평균시) |
| 1908-04-01 ~ 1912-01-01 | +8:30 |
| 1912-01-01 ~ 1954-03-21 | +9 |
| 1954-03-21 ~ 1961-08-10 | +8:30 |
| 1961-08-10 ~ | +9 |

- 서머타임(+1시간)이 있었던 해: 1948–51, 1955–60, 1987–88. `dst: true` 구간이다.
- 서머타임 시작으로 시계를 앞당긴 구간의 시각은 실제로 없던 시각이다. 이런 입력은 직전 표준시로 계산하고 경고한다.
- 서머타임 종료로 시계를 되돌린 구간의 시각은 두 번 있었다. 이런 입력은 앞쪽(서머타임) 시각으로 계산하고 경고한다.

### 한국천문연구원 Open API (선택)
- 공공데이터포털의 `LrsrCldInfoService`(음양력)와 `SpcdeInfoService/get24DivisionsInfo`(24절기, `kst` 필드에 HHMM)가 있다.
- 서비스키가 필요하고, 이용허락범위는 "제한 없음"이다.
- 앱은 실행 중에 이 API를 부르지 않는다. 키를 받으면 대량 대조 스크립트로만 쓸 계획이다.
- 한국천문연구원 웹페이지에는 공공누리 표시가 없다. 그래서 `tests/fixtures/kasi-solar-terms.json`(192개 시각)은 **검증 전용**으로만 저장했고 앱 데이터로 쓰지 않는다.

## 2. 사주 계산 규칙

| 항목 | 규칙 | 코드 |
|---|---|---|
| 연주 | 출생 **순간(UTC)**이 입춘 순간 이후면 그해. 간지 = (연도 − 4) mod 60 | `computeSaju` |
| 월주 | 직전 12절(소한=축 … 대설=자). 월간은 연간으로 정함: 갑기년 병인월, 을경년 무인월, 병신년 경인월, 정임년 임인월, 무계년 갑인월 | 〃 |
| 일주 | JDN + 49 mod 60 (2000-01-01 = 무오). 보정 시각 기준 날짜 | `dayPillarOf` |
| 시주 | 보정 시각으로 시지를 정함(자 23–01, 축 01–03 …). 시간은 일간으로 정함: 갑기일 갑자시 … 23–24시는 다음 날 자시의 천간 | `dayAndHour` |
| 자시 기준 | 기본 **23시에 날이 바뀜**. 선택: 0시(야자시·조자시). 어느 쪽이든 시주는 같고 일주만 달라짐 | `dayBoundary` |
| 시간 보정 | 기본 **경도 보정**(지방평균시 = UTC + 경도×4분, 서울 −32.1분). 선택: 진태양시(+균시차, astronomy-engine 태양 시각), 표준시(서머타임만 제거) | `solarLocalMs` |
| 오행 분포 | 천간 4 + 지지 4 글자 수 (지장간 제외) | – |
| 십신 | 일간 대비 오행 생극 + 음양. 지지는 정기(본기) 천간 기준 → 자=계, 오=정, 사=병, 해=임 | `tenGod` |
| 지장간 | 국내 통용 월률분야표(연해자평 계열), 신(申)의 여기는 무(戊) | `BRANCHES.hidden` |
| 12운성 | 양간 순행·음간 역행, 토는 화를 따름(화토동법). 장생: 갑-해, 을-오, 병·무-인, 정·기-유, 경-사, 신-자, 임-신, 계-묘 | `twelveStage` |
| 대운 | 양년생 남·음년생 여는 순행(다음 절까지), 음년생 남·양년생 여는 역행(이전 절부터). 일수 ÷ 3 = 시작 나이(년). **대운수는 반올림**(최소 1)이고, 정확한 시작 연월은 따로 표시 | `computeSaju` |
| 세운 | 올해부터 10년. 해의 간지는 입춘에 바뀜 | 〃 |
| 격국 | **MVP 제외**. 유파 차이가 커서 2단계에서 규칙을 정해 넣는다 | – |

- 연주·월주는 절기 순간과 출생 순간을 직접 비교하므로 시간 보정과 관계없다.
- 출생 순간이 절입과 2시간 이내면 경고한다. 보정 시각이 시진 경계와 10분 이내여도 경고한다.
- 보정 방식이나 자시 기준에 따라 일주·시주가 달라지면 6가지 조합의 결과를 함께 보여 준다.
- 입력 범위: 양력 1900–2100년, 음력은 2050-11-18까지. 출생지는 한반도(경도 120–135°)만 받는다.

### 이미지 저작권
- 그림을 그린 Pamela Colman Smith는 1951년, 글을 쓴 A. E. Waite는 1942년에 사망했다.
  - 미국: 1931년 이전 출판물이라 퍼블릭 도메인이다.
  - 영국·EU: 사후 70년이 지나 2022-01-01부터 퍼블릭 도메인이다.
  - 한국: 1957년 법(사후 30년) 기준으로 이미 만료됐고, 1987년 법 부칙에 따라 다시 보호되지 않는다. 1996년 외국인 저작물 소급 보호는 1957년 이후 사망자만 대상이라 이 두 사람은 해당하지 않는다.
- **쓰지 않는 것**: U.S. Games Systems의 1971년 재채색판, 카드 뒷면, 상자 그림.
- **상표**: "RIDER-WAITE", "THE RIDER TAROT DECK", "SMITH-WAITE TAROT DECK"은 미국 등록 상표다. 앱 이름과 문구에 쓰지 않고 "웨이트–스미스 1909 덱"으로 표기한다. 한국 등록 여부(KIPRIS)는 아직 확인하지 않았다.
- **풀이 문장**: Biddy Tarot, Labyrinthos 같은 현대 사이트·책은 저작권이 있어 베끼지 않는다.

### 섞기
- `crypto.getRandomValues`로 Fisher–Yates 섞기를 한다. 모듈로 치우침은 거부 표본추출로 없앤다.
- 역방향 확률은 50%이고 끌 수 있다. 균등성은 카이제곱 검정으로 확인한다(`tests/tarot.test.ts`).
